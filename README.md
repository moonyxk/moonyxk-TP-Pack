## Installation

1. `moonyxk.Pack.zip` herunterladen (nicht entpacken).
2. In Minecraft: **Optionen → Ressourcenpakete → Pack-Ordner öffnen**.
3. Die ZIP-Datei in den Ordner `resourcepacks` ziehen.
4. Das Pack in Minecraft aktivieren.
